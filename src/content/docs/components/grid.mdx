Responsive layout container. Applies the `.container` class which provides a max-width, centered layout using CSS grid.

## Example

<div class="doc-preview" style="flex-direction: column; width: 100%">
  <Grid>
    <div class="row">
      <div class="col-4" style="background: var(--muted); padding: 1rem; border-radius: var(--radius-small); text-align: center">col-4</div>
      <div class="col-4" style="background: var(--muted); padding: 1rem; border-radius: var(--radius-small); text-align: center">col-4</div>
      <div class="col-4" style="background: var(--muted); padding: 1rem; border-radius: var(--radius-small); text-align: center">col-4</div>
    </div>
    <div class="row" style="margin-top: 1rem">
      <div class="col-8" style="background: var(--muted); padding: 1rem; border-radius: var(--radius-small); text-align: center">col-8</div>
      <div class="col-4" style="background: var(--muted); padding: 1rem; border-radius: var(--radius-small); text-align: center">col-4</div>
    </div>
  </Grid>
</div>

## Usage

```html
<div class="container">
  <div>Column 1</div>
  <div>Column 2</div>
  <div>Column 3</div>
</div>
```

## Astro

```astro
import Grid from 'src/components/grid/grid.astro';

<Grid>
  <div>Column 1</div>
  <div>Column 2</div>
  <div>Column 3</div>

```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `pClass` | `string` | — | Additional CSS classes |

## CSS Custom Properties

| Property | Default | Description |
|----------|---------|-------------|
| `--grid-cols` | `12` | Number of columns |
| `--grid-gap` | `1.5rem` | Gap between columns |
| `--container-max` | `1280px` | Maximum container width |
| `--container-pad` | `1rem` | Container horizontal padding |
