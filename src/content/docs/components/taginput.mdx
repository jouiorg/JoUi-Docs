## Usage

```html
<ot-taginput>
  <input placeholder="Add tags…" />
</ot-taginput>

<!-- With pre-populated tags -->
<ot-taginput value="design, development, css">
  <input placeholder="Add tags…" />
</ot-taginput>

<!-- Disabled -->
<ot-taginput disabled>
  <input placeholder="Add tags…" />
</ot-taginput>

<script type="module" src="/path/to/taginput.js"></script>
```

## Keyboard interaction

| Key | Action |
|-----|--------|
| `Enter` or `,` | Confirm current input as a tag |
| `Backspace` (on empty input) | Remove last tag |
| `Escape` | Clear current input |

## Astro

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `pValue` | `string` | — | Comma-separated initial tags |
| `pDisabled` | `boolean` | `false` | Disabled state |
| `pPlaceholder` | `string` | `'Add tags…'` | Input placeholder text |
| `pClass` | `string` | — | Additional CSS classes |

## Value format

Tags are stored as a comma-separated string in the `value` attribute. To read the current tags in a form, read the `value` property of the `ot-taginput` element.

## CSS Custom Properties

No component-specific CSS variables. Appearance is controlled by the global design tokens in `tokens.css`.
