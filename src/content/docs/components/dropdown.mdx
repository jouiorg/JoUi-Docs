Accessible dropdown menu built as a Web Component (`ot-dropdown`). Handles keyboard navigation and click-outside closing automatically. Uses the native Popover API.

## Example

<div class="doc-preview">
  <Dropdown>
    <button popovertarget="demo-dd" class="btn btn--outline btn--md">Options ▾</button>
    <div id="demo-dd" popover>
      <a href="#" role="menuitem">Edit</a>
      <a href="#" role="menuitem">Duplicate</a>
      <hr />
      <a href="#" role="menuitem">Delete</a>
    </div>
  </Dropdown>
</div>

## Usage

```html
<ot-dropdown>
  <button popovertarget="my-dropdown" class="btn btn--outline btn--md">Options ▾</button>
  <div id="my-dropdown" popover>
    <a href="#" role="menuitem">Edit</a>
    <a href="#" role="menuitem">Duplicate</a>
    <hr />
    <a href="#" role="menuitem">Delete</a>
  </div>
</ot-dropdown>

<script type="module" src="/path/to/dropdown.js"></script>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `pClass` | `string` | — | Additional CSS classes on the `ot-dropdown` element |

## CSS Custom Properties

No component-specific CSS variables. Appearance is controlled by the global design tokens in `tokens.css`.

## Accessibility

- Keyboard navigation: `Arrow Down` / `Arrow Up` moves between items, `Escape` closes
- `aria-expanded` is toggled on the trigger automatically
