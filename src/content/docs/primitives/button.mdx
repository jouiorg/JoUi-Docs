Triggers an action or event. Renders as `<button>` or `<a>` when `pHref` is provided.

## Usage

```html
<button class="btn btn--primary btn--md">Button</button>
<button class="btn btn--outline btn--sm">Outline</button>

<!-- As link -->
<a href="/page" class="btn btn--primary btn--md">Link</a>

<!-- Submit -->
<button type="submit" class="btn btn--primary btn--md">Submit</button>
```

## Astro

```astro
import Button from 'src/primitives/button/button.astro';

<Button pVariant="primary" pSize="md">Click</Button>
<Button pHref="/page" pVariant="outline">Link</Button>
<Button pType="submit" pVariant="primary">Submit</Button>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `pVariant` | `'primary' \| 'secondary' \| 'outline' \| 'ghost'` | `'primary'` | Visual style |
| `pSize` | `'sm' \| 'md' \| 'lg'` | `'md'` | Button size |
| `pHref` | `string` | — | If set, renders as `<a>` |
| `pType` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native button type (ignored when `pHref` is set) |
| `pDisabled` | `boolean` | `false` | Disabled state |
| `pClass` | `string` | — | Additional CSS classes |

|----------|---------|-------------|
| `--btn-gap` | `0.5rem` | Gap between icon and label |

| `--btn-padding-x` | `1rem` | Horizontal padding |

| `--btn-border-width` | `1px` | Border width |

## Accessibility

- Use `pHref` for navigation — renders semantic `<a>`
- Links with `pDisabled` use `aria-disabled="true"` (not `disabled`, which is invalid on anchors)
- Use `pType="submit"` for form submission buttons
