Placeholder that mimics content layout while data is loading. Animates with a shimmer effect.

## Usage

```html
<!-- Line (full width) -->
<div role="status" class="skeleton line" aria-label="Loading…"></div>

<!-- Line with custom width -->
<div role="status" class="skeleton line" style="width: 60%" aria-label="Loading…"></div>

<!-- Box -->
<div role="status" class="skeleton box" aria-label="Loading…"></div>
```

## Astro

```astro
import Skeleton from 'src/primitives/skeleton/skeleton.astro';

<Skeleton pType="line" />
<Skeleton pType="line" style="width: 60%" />
<Skeleton pType="box" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `pType` | `'line' \| 'box'` | `'line'` | Shape — line is full-width, box is 4rem × 4rem |
| `pClass` | `string` | — | Additional CSS classes |

## CSS Custom Properties

No component-specific CSS variables. Appearance is controlled by the global design tokens in `tokens.css`.

## Accessibility

- Uses `role="status"` so screen readers announce loading state changes
- `aria-label="Loading…"` is set automatically
