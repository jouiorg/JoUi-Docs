Standalone utility CSS files for navigation, backgrounds, table base, and height helpers. These live in `src/styles/custom/`, `src/styles/main/`, and `src/styles/style/`.

In Drupal they are loaded per SDC component. In Astro, import the ones you need in `Layout.astro` or a specific page layout.

---

## Navigation — `custom/nav.css`

Base styles for `<nav class="menu">` using the joui public/private var pattern. Works for horizontal navbars, vertical menus, and footers.

```html
<nav class="menu">
  <ul>
    <li><a href="/" class="is-active">Home</a></li>
    <li><a href="/about">About</a></li>
  </ul>
</nav>
```

### CSS custom properties

| Property | Default | Description |
|---|---|---|
| `--nav_d` | `flex` | display |
| `--nav_f-d` | `row` | flex-direction |
| `--nav_f-w` | `nowrap` | flex-wrap |
| `--nav_r-gap` | `18px` | row gap |
| `--nav_c-gap` | `36px` | column gap |
| `--nav_gap` | `r-gap c-gap` | shorthand gap override |
| `--nav_m-b` | `0px` | margin-block |
| `--nav_m-i` | `0px` | margin-inline |
| `--nav_p` | `0px` | padding |
| `--nav_l-s` | `none` | list-style |
| `--nav_link_c` | `--c_fg` | link color |
| `--nav_link_c_h` | `--c_accent` | link hover color |
| `--nav_link_c_a` | `--c_accent` | active link color |
| `--nav_link_f-s` | `--f-s_6` | link font-size |
| `--nav_link_f-w` | `--f-w_md` | link font-weight |
| `--nav_link_p-b` | `0.5em` | link padding-block |
| `--nav_link_p-i` | `0px` | link padding-inline |

Vertical menu example:

```html
<nav class="menu" style="--nav_f-d: column; --nav_c-gap: 0; --nav_r-gap: 8px;">
  <ul>
    <li><a href="/">Home</a></li>
    <li><a href="/about">About</a></li>
  </ul>
</nav>
```

## Backgrounds — `main/backgrounds.css`

`.bg-{variant}` sets a background + foreground color pair. Override per-instance via custom properties.

```html
<section class="bg-secondary">
  <p>Secondary background section</p>
</section>
```

### CSS custom properties

| Property | Default | Description |
|---|---|---|
| `--is-bg_bg` | `transparent` | background color |
| `--is-bg_c` | `inherit` | text color |
| `--is-bg_bg_secondary` | `--c_bg_subtle` | `.bg-secondary` background |

Custom background:

```html
<div class="bg-secondary" style="--is-bg_bg_secondary: var(--c_accent_subtle); --is-bg_c: var(--c_accent_fg);">
  Custom accent background
</div>
```

## Table — `style/table.css`

Base styles applied directly to `<table>` — no extra class needed. Full-width, bordered, with hover row highlight.

```html
<table>
  <thead>
    <tr>
      <th>Name</th>
      <th>Status</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Alice</td>
      <td>Active</td>
    </tr>
  </tbody>
</table>
```

Styles use `--b-w`, `--b-s`, `--c_border_muted`, `--c_bg_subtle`, `--c_hover_bg`, `--f-s_7` — all from `tokens.css`. No additional custom properties exposed.

## Heights — `custom/heights.css`

Utility classes for Drupal toolbar offset support and minimum full-viewport height.

```html
<div class="min-height">
  Full viewport height, accounting for Drupal toolbar.
</div>
```

| Class | Effect |
|---|---|
| `.align-top` | `top: var(--drupal-displace-offset-top, 0)` |
| `.min-height` | `min-height: 100dvh` minus toolbar offset |

`--drupal-displace-offset-top` is injected by Drupal's toolbar module. In non-Drupal contexts it defaults to `0` and the classes behave as standard viewport utilities.
